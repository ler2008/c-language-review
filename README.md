## 功能

- **三语言模式**：右上角切换 C / C++ / Python，题干中的代码、选项、填空答案、参考程序、解析和采分点同步切换。
- **三种题型**：选择题即时判分；程序填空对照每个空的答案与说明；程序设计提供完整可运行参考程序和采分点。
- **触感反馈**：手机端答题正确/错误、收藏、切换语言时提供短震动；桌面端提供按压、涟漪、弹跳与错误抖动等视觉反馈，可在右上角关闭。
- **苹果风界面**：大字号标题、留白、磨砂顶栏、胶囊按钮、圆角卡片、克制的阴影与深色模式。
- **代码书写区**：程序填空与程序设计题内置代码编辑区，支持行号、Tab 缩进、回车自动缩进、一键插入模板、复制与清空；草稿按「语言 + 题目」自动保存，切换语言或刷新页面都不会丢。
- **做完可检查**：填空题按空判分，全部正确自动计入正确率并揭晓解析，有空错误会标红并收进错题本；编程题先做结构与语法检查，Python 模式还能在浏览器里用题目样例自动运行判题（首次需联网加载运行环境），C/C++ 因浏览器无法编译，改为「本地运行样例后确认」，同样计入对错与错题本。
- **答错即讲知识点**：选择/填空/设计题答错或标记「未掌握」后，解析下方自动展开对应知识点卡片——概念、3 条要点、当前语言的写法示例和常见易错点（共 37 个主题，按题目标签匹配，覆盖全部题目）。
- **本地账号与独立错题本**：右上角「登录」可注册/登录本机账号；每个账号有独立的进度、错题本与收藏，游客数据与账号数据互不影响，首次登录会把游客进度带入新账号。账号使用加盐 SHA-256 保存在本机，不上传服务器。
- **筛选与搜索**：按模块、题型、难度、未做/错题/收藏筛选，支持题干、选项、知识点关键词搜索。
- **学习进度**：三种语言分别记录作答、正确率、错题、收藏和完成度，数据保存在浏览器 `localStorage`。
- **答题卡**：440 格答题卡，颜色区分正确/错误/已看答案，点击题号快速跳转。
- **乱序练习 / 随机抽题**：避免按固定顺序背题。
- **移动端适配、代码复制、快捷键 `/` 聚焦搜索**。
- 无后端、无第三方依赖；部署到任意静态托管后即可在微信内打开。

## 重新生成题库

修改 `data/raw/*.json` 或 `data/variants/*.json` 后，在项目根目录执行：

```bash
python tools/build_data.py
python tools/package_site.py
```

脚本会校验字段、ID、题型数量、模块数量、三语言变体、答案下标、重复题干、代码围栏等，并生成 `assets/js/data.js`。只做校验不写入：

```bash
python tools/build_data.py --check
```

## 说明

- 题目与解析为围绕大学《程序设计基础》常见教学大纲原创整理，**不是**官方题库，也不保证与某一版教材的课后题逐题对应。
- C 版本以 C99/C11 语义为准；C++ 版本使用标准 C++17；Python 版本使用 Python 3.10+，不依赖第三方库。
- 涉及 `sizeof`、内存对齐、整数溢出等题目已在题干中写明环境假设；不同编译器对个别实现定义行为可能有差异，题目已尽量避免依赖这些行为。
- 三语言模式共用 440 道题，切换语言不会改变题量；学习进度按语言分别保存，清理浏览器缓存或换设备后不会自动同步。
- 账号为**纯前端本地账号**：密码加盐哈希后存在本机 `localStorage`，不发送到任何服务器；换浏览器或清除站点数据后需要重新注册，错题本也会随数据一起清除。若需要跨设备同步，需要另接后端或 Supabase/Firebase 等服务。
- 知识点卡按题目标签自动匹配（`data/knowledge.json`），每题至少命中 1 张、最多 2 张；想补内容可直接编辑该文件后重新构建。
- 题目仅用于课程复习与自测，欢迎按 `data/SCHEMA_V2.md` 的格式自行扩充。
