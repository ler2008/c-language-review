# 题库数据规范（v1）

每个原始文件是一个 **JSON 数组**，数组元素为一道题。全部使用 UTF-8 无 BOM 编码，字符串内换行用 `\n`。

## 公共字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 模块内唯一编号，如 `数-01`、`指-12`、`结-03` |
| `module` | string | 是 | 只能是：`C语言基础`、`数组`、`指针`、`结构体`、`枚举`、`函数` |
| `type` | string | 是 | `choice`（选择）、`fill`（程序填空）、`design`（程序设计） |
| `difficulty` | number | 是 | 1=基础，2=中等，3=较难 |
| `tags` | string[] | 是 | 2~4 个知识点标签，如 `["二维数组","指针"]` |
| `stem` | string | 是 | 题干。可含行内代码反引号与 ```c 代码块；不要写 HTML |
| `analysis` | string | 是 | 答案解析。先讲知识点，再解释为什么对/错；可含代码块 |

## 选择题（choice）

额外字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `options` | string[] | 是 | 恰好 4 个选项，**不要**带 `A.` `B.` 前缀 |
| `answer` | number | 是 | 正确选项下标，0=A，1=B，2=C，3=D |

要求：四个选项互斥，只有一个无争议的正确答案；错误选项要像真实错误（概念混淆、边界错误、优先级错误等），不要凑数。

## 程序填空题（fill）

额外字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `blanks` | object[] | 是 | 2~4 个空，按顺序排列 |
| `blanks[].no` | string | 是 | `①` `②` `③` `④` |
| `blanks[].answer` | string | 是 | 标准答案（尽量短，一条表达式或一条语句） |
| `blanks[].note` | string | 否 | 该空的补充说明/等价写法 |

要求：`stem` 中必须出现与 `blanks[].no` 对应的 `①` `②` 占位符；整段程序在填入答案后可编译运行；答案尽量唯一，若有等价写法在 `note` 中说明。

## 程序设计题（design）

额外字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `solution` | string | 是 | 完整、可编译的参考程序（含 `#include` 与 `main`） |
| `points` | string[] | 是 | 3~5 条评分/采分点，PTA 风格 |

要求：`stem` 写清输入格式、输出格式、输入样例、输出样例（用代码块呈现）；`analysis` 写思路、关键算法、复杂度与易错点；`solution` 使用标准 C（C99/C11），不使用 `gets`、`conio.h`、`system("pause")` 等。

## 选择题示例

```json
{
  "id": "数-01",
  "module": "数组",
  "type": "choice",
  "difficulty": 1,
  "tags": ["一维数组", "初始化"],
  "stem": "若有定义 `int a[5] = {1, 2};`，则 `a[4]` 的值是（ ）。",
  "options": ["0", "2", "随机值", "编译错误"],
  "answer": 0,
  "analysis": "数组部分初始化时，未显式赋值的元素会被自动初始化为 0，因此 a[2]、a[3]、a[4] 均为 0。若数组定义在函数内部且写作 `int a[5];`（完全不初始化），其元素才是未定义的随机值。"
}
```

## 程序填空示例

```json
{
  "id": "数-20",
  "module": "数组",
  "type": "fill",
  "difficulty": 2,
  "tags": ["一维数组", "循环", "求和"],
  "stem": "下面程序求数组所有元素之和，请填空。\n\n```c\n#include <stdio.h>\nint main(void)\n{\n    int a[6] = {1, 2, 3, 4, 5, 6}, i, sum = 0;\n    for (i = 0; i < 6; i++)\n        sum += ①;\n    printf(\"%d\\n\", sum);\n    return 0;\n}\n```",
  "blanks": [
    { "no": "①", "answer": "a[i]", "note": "也可写成 *(a + i)" }
  ],
  "analysis": "循环变量 i 从 0 到 5，依次访问 a[0]~a[5]。累加表达式为 a[i]，最终输出 21。"
}
```

## 程序设计示例

```json
{
  "id": "数-40",
  "module": "数组",
  "type": "design",
  "difficulty": 2,
  "tags": ["一维数组", "统计"],
  "stem": "输入 10 个整数，输出其中的最大值及其下标（下标从 0 开始，若有多个最大值，输出首次出现的下标）。\n\n**输入格式：** 一行 10 个整数。\n\n**输出格式：** `最大值 下标`。\n\n**输入样例：**\n```text\n3 1 9 9 2 5 7 0 4 6\n```\n**输出样例：**\n```text\n9 2\n```",
  "analysis": "先假设 a[0] 最大，再从下标 1 开始遍历；只有严格大于当前最大值时才更新，因此多个最大值会保留首次出现的下标。时间复杂度 O(n)。",
  "solution": "#include <stdio.h>\n\nint main(void)\n{\n    int a[10], i, max, pos = 0;\n    for (i = 0; i < 10; i++)\n        scanf(\"%d\", &a[i]);\n    max = a[0];\n    for (i = 1; i < 10; i++) {\n        if (a[i] > max) {\n            max = a[i];\n            pos = i;\n        }\n    }\n    printf(\"%d %d\\n\", max, pos);\n    return 0;\n}",
  "points": [
    "正确定义数组并读入 10 个整数",
    "正确初始化最大值与下标",
    "使用严格大于更新，保证多个最大值取首次下标",
    "按格式输出最大值与下标"
  ]
}
```
