# 把题库发到微信、在线做题

微信内置浏览器**不能直接打开本地文件**（`file://`），所以需要先把整个网页上传到一个 **HTTPS 公网地址**，再把链接发到微信。网页是纯静态的，不需要服务器、数据库或后端。

推荐顺序：

1. **腾讯云 CloudBase 静态网站托管**（推荐，国内访问稳定）
2. **Netlify Drop**（最快，拖拽上传，国内速度一般）
3. **Vercel**（有 Node.js 环境时方便）
4. 已有微信小程序时，用**微信云开发静态托管**

---

## 一、先打包上传目录

在项目根目录执行：

```bash
python tools/package_site.py
```

会生成：

```text
dist/
├── index.html
└── assets/
    ├── css/style.css
    └── js/
        ├── app.js
        └── data.js
```

上传时注意：**`index.html` 必须在网站根目录**。如果上传后访问首页 404，通常是把 `dist` 文件夹本身传上去了，应该上传 `dist` 里面的内容。

---

## 二、腾讯云 CloudBase 静态网站托管（推荐）

适合长期放在微信里用，国内访问比国外静态托管稳定。

### 控制台操作

1. 注册/登录腾讯云，完成实名认证。
2. 打开云开发 CloudBase 控制台：<https://console.cloud.tencent.com/tcb>
3. 新建环境，地域选择离你较近的（如上海/广州），套餐按量计费即可，记下 **环境 ID**。
4. 进入该环境 → **静态网站托管** → 开通。
5. 进入静态网站托管的文件管理，上传 `dist/` 里的全部内容：
   - `index.html`
   - `assets/` 整个目录
6. 在静态网站托管页面找到**默认域名**，形如：

   ```text
   https://<环境ID>.tcloudbaseapp.com
   ```

7. 手机或电脑浏览器打开该域名，确认能显示 300 题页面。
8. 把这个链接发到微信（文件传输助手、群聊或好友），点击即可在线做题。

> 默认域名可以直接用 HTTPS 访问，适合个人复习和小范围分享。若用于正式教学、对外宣传，建议绑定已备案的自定义域名，减少微信“非官方网页”提示。

### 命令行部署（可选）

本机有 Node.js 时，也可以直接用 CloudBase CLI 更新：

```bash
npm i -g @cloudbase/cli
tcb login
tcb hosting deploy ./dist -e <环境ID>
```

以后改完题库，重新执行：

```bash
python tools/build_data.py
python tools/package_site.py
tcb hosting deploy ./dist -e <环境ID>
```

## 三、Netlify Drop（最快，无需服务器）

1. 执行 `python tools/package_site.py`，得到 `dist/`。
2. 打开 <https://app.netlify.com/drop>。
3. 把 `dist` 文件夹拖进页面。
4. 等待上传完成，会得到一个 HTTPS 地址，形如：

   ```text
   https://随机名称.netlify.app
   ```

5. 把地址发到微信即可。

注意：Netlify 的节点在海外，国内/微信访问速度可能不稳定；适合临时分享和测试。要长期保留站点，需要注册 Netlify 账号并认领该站点。

---

## 四、Vercel（可选）

有 Node.js 环境时：

```bash
npx vercel ./dist --prod
```

按提示登录后得到 `https://xxx.vercel.app`。国内访问同样可能不稳定，适合临时使用。

---

## 五、微信云开发静态托管（已有小程序时）

如果已经有微信小程序并开通了云开发：

1. 进入微信开发者工具 → 云开发控制台。
2. 选择 **静态网站托管**。
3. 上传 `dist/` 中的文件。
4. 使用控制台提供的默认域名访问，或绑定已备案域名。

这种方式和腾讯云 CloudBase 本质相同，适合已经在做小程序的情况。

---

## 六、在微信里“固定”这个题库

网页本身不能像小程序一样被安装，但可以用下面几种方式固定入口：

- **微信收藏**：打开链接 → 右上角 `···` → 收藏。之后在“我 → 收藏”里直接进入。
- **浮窗**：打开链接 → 右上角 `···` → 浮窗。适合边看资料边做题。
- **发送到文件传输助手**：把链接发给自己，聊天记录就是入口。
- **添加到桌面**：
  - Android：在手机浏览器打开链接 → 菜单 → 添加到桌面。
  - iPhone：用 Safari 打开 → 分享 → 添加到主屏幕。
- **公众号菜单/自动回复**：已认证公众号可在后台把链接配置到自定义菜单；这需要公众号主体和域名配置，个人复习不必折腾。

---

## 七、分享卡片与域名注意事项

- 页面已经加了 `og:title`、`og:description`，微信分享时会读取标题和描述。
- 默认分享缩略图由微信抓取页面图片；若想指定分享封面，需要：
  1. 使用已认证的公众号；
  2. 配置 JS 接口安全域名；
  3. 接入微信 JS-SDK 的 `updateAppMessageShareData`。
  
  仅个人做题不需要这一步。
- 自定义域名在中国大陆需要 **ICP 备案**；CloudBase/Netlify/Vercel 提供的默认域名可直接测试。
- 如果微信打开提示“非官方网页”，通常是域名未备案或未认证，不影响做题，但正式对外使用建议备案域名。

---

## 八、学习记录说明

- 作答记录、错题、收藏保存在**当前浏览器**的 `localStorage`。
- 微信内置浏览器、手机浏览器、电脑浏览器各自独立，不会自动同步。
- 清理微信缓存、清理浏览器数据或换设备后，记录会丢失。
- 如果需要“登录 + 多设备同步”，需要再加云端数据库和用户系统；当前版本刻意保持纯静态、零后端。
